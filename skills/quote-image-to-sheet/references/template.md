# 报价模板

模板来源由使用者自行配置。仓库不公开私人 Google Sheets 地址。

默认使用 assets/template.xlsx 缓存，不联网刷新。仅用户更换模板或明确要求最新版本时读取此来源。刷新时重新核对页签和结构；目标表的 sheetId 必须从导入结果的元数据获取。

刷新缓存：导出并下载上述模板，确认只有普通单页单元格和图片，字段位置仍符合下面映射，再执行 `python scripts/build_quote.py cache-template <下载.xlsx> <skill>/assets/template.xlsx`。该命令删除旧项目数据、共享字符串与旧图片，保留样式和单价；结构改变时先适配程序并测试，不能直接覆盖缓存。

当前结构：C2 总标题；C3 供应商；第4行表头；第5行起物件；7项示例的总价行是第12行。

| 列 | 含义 | 处理 |
|---|---|---|
| B | 序号 | 1..N |
| C | 品类名称 | 原模板空白，不杜撰分类 |
| D | 图片 | 左侧制作图 |
| E | 物件名称（表头当前空白） | 按原图名称填写，保留模板布局 |
| F | 单价/天（元） | 模板目前1300，沿用但不能从图片推断 |
| G | 人天数 | 真空白 |
| H | 价格合计（元） | 自动计算 F×G，未填天数显示空白 |
| I/J | 开始/提交日期 | 生成当天 / 附图截止日期，yyyy-mm-dd |
| K/L | 状态/备注 | 清空旧项目内容 |

总价行保留“总价”标签，金额自动 SUM 所有项目，全部未填时显示空白。保留模板蓝色标题、表头、总价底色及边框。不要擅自覆盖模板或公开文件。
